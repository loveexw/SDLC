# Пользовательский интерфейс на чистом WinAPI

## Контекст и постановка задачи
Нужен оконный интерфейс для Windows на C++.

## Драйверы решения
- без сторонних фреймворков и их установки;
- малый размер и простое развёртывание;
- отделение интерфейса от логики.

## Рассмотренные варианты
- WinAPI + Common Controls;
- Qt Widgets;
- консольное меню.

## Итог решения
Интерфейс написан на **WinAPI с Common Controls v6**: ListView, ComboBox, DateTimePicker. Окна создаются программно, общий код вынесен в базовый класс `Form`. Бизнес-логика находится в ядре и не зависит от WinAPI.

### Последствия
- Хорошо: один exe-файл, сборка средствами Visual Studio без дополнительных пакетов.
- Хорошо: поддержка масштабирования DPI и визуальных стилей Windows.
- Плохо: больше ручного кода разметки, чем в Qt.

### Подтверждение
Прототипы окон описаны в `sysml/Mockups.sysml` и согласованы с заказчиком; соответствие реализации прототипам проверяется демонстрацией в конце итераций 2–4.

## Плюсы и минусы вариантов
### WinAPI
- Хорошо: нативно, без зависимостей.
- Плохо: многословно.
### Qt
- Хорошо: удобный дизайнер форм.
- Плохо: установка Qt, большой размер дистрибутива.
### Консоль
- Хорошо: просто.
- Плохо: неудобно выбирать дату, время и комнату.

## Дополнительная информация
Требования SRS: REQ-INT-001, REQ-PORT-001. Системные требования: SYS-06, SYS-14, SYS-18. Функции: F03, F10.
